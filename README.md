# WatchNSync

WatchNSync is a shared video-watching application that will keep viewers in sync.

## Current stack

React, TypeScript, Vite, Node.js, Express, and Socket.IO.

## Status

Project scaffold only; product features have not been implemented.

## Local development

Install dependencies, then run the frontend development server:

```bash
npm install
npm run dev
```

The future backend entry point is available with `npm run dev:server`. Build both parts with `npm run build`.
